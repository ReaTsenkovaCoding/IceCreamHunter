🚗🍦 Ice Cream Hunter 🍦🚗
(Available for Windows ONLY)  
----------------------------

🎮 Gameplay
--------------

 - Pick up ice cream packages
 - Deliver them to the correct customers (little monsters hiding behind trees, houses, street lights, etc.)
 - Beat the 2:30-minute timer
 - Use boost pickups to move faster
 - Avoid mistakes — wrong actions trigger error sounds
 - Win by delivering all packages
 - Lose when time hits zero

🕹 Controls
-------------

Key	Action
 - W / Up Arrow	Drive forward
 - S / Down Arrow	Reverse
 - A / Left Arrow	Turn left
 - D / Right Arrow	Turn right

⚡ Features
--------------

- Smooth 2D car controller
- Boost pickups with particles & SFX
- Clean UI (timer, deliveries, messages)
- Game over & win screens
- Background music (made with AI) + SFX (taken from https://mixkit.co/free-sound-effects/)


📦 How to Play
-----------------

 - Open the Google Drive link
 - Download the .zip from Releases
 - Extract ICE CREAM HUNTER-v1.0-Windows
 - run IceCreamHunter.exe

🛠 Built With
--------------

 - Unity 2022+
 - C#
 - TextMeshPro
 - Unity Input System

📁 Project Structure
----------------------

This repo contains:
 - Assets/ — game scripts, art, scenes
 - ProjectSettings/ — Unity project configuration
 - .gitignore — Unity-safe ignores
 - The repo does NOT include Library or Build folders, so cloning is clean.
